# MilkGuard Online MVP
Digital proof-of-concept for smartphone-based preliminary milk adulteration screening.

**Important:** the included model uses SYNTHETIC feature data. It is not validated for real milk testing.

## Run
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Demo wording
“Our current digital MVP demonstrates the AI pipeline using synthetic image-derived features. The next validation stage is controlled real-sample data collection, batch-separated validation and reference-test comparison.”
